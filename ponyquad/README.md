# Ponyquad
Ponyquad is a small set of bindings to Macroquad for PonieScript. Macroquad is
the perfect small game engine to prototype PonieScript's Rust integrations on
top of, and that is what this is about.

The main goal with Ponyquad is to have a nice testing ground for building new
PonieScript features, without having to write an entire game engine as well.

This includes the hot reloading feature, which, while maybe not perfect, would
be nice to have working in some form for PonieScript.
